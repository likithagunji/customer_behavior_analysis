# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project is a hands-on **Data Analytics portfolio project** focused on analyzing customer shopping behavior and extracting meaningful business insights from raw data.

The project demonstrates an end-to-end analytics workflow using **Python, PostgreSQL, SQL, and Power BI**, followed by a project report and presentation.

**Workflow:**
Data Preparation → EDA → Data Cleaning → SQL Analysis → Power BI Dashboard → Report → Presentation

---

## 🎯 Objectives

* Understand customer shopping behavior
* Clean and prepare raw data for analysis
* Perform exploratory data analysis using Python
* Analyze data using PostgreSQL and SQL
* Identify customer and purchasing patterns
* Build an interactive Power BI dashboard
* Communicate findings through a report and presentation

---

## 📊 Dataset

The project uses a **Customer Shopping Behavior** dataset containing information related to customer demographics, purchases, product categories, shopping behavior, and transaction-related attributes.

The dataset was explored and prepared in Python before being loaded into PostgreSQL for SQL-based analysis.

## 🔄 Project Workflow

### 1. Data Loading & Exploration

The dataset was imported into Python using Pandas and initially analyzed to understand its structure, dimensions, data types, and statistical characteristics.

### 2. Data Cleaning

Data preparation included:

* Checking missing values
* Identifying duplicate records
* Checking and correcting data types
* Standardizing data where required
* Handling inconsistent values
* Creating derived columns

### 3. Exploratory Data Analysis

EDA was performed using Python and Pandas to identify patterns and trends related to:

* Customer demographics
* Age distribution
* Customer segments
* Product categories
* Purchase behavior
* Sales-related patterns
* Subscription behavior

### 4. Feature Engineering

Additional analytical columns were created to support deeper analysis.

For example, customers were categorized into age groups using quartile-based segmentation.

### 5. PostgreSQL & SQL Analysis

The cleaned dataset was loaded into **PostgreSQL** for structured analysis.

SQL queries were used to investigate:

* Customer segmentation
* Purchase frequency
* Product category performance
* Customer spending patterns
* Sales analysis
* Subscription behavior
* Customer loyalty patterns

### 6. Power BI Dashboard

An interactive **Power BI dashboard** was created to communicate the analysis through:

* KPI cards
* Customer metrics
* Sales metrics
* Category analysis
* Customer segmentation
* Purchase trends
* Interactive filters and slicers
